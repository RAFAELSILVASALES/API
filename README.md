# 🚀 Estudos de API: Do Conceito à Prática

Repositório dedicado ao meu aprendizado, evolução e prática sobre **APIs (Application Programming Interfaces)**. Aqui centralizo resumos teóricos, exemplos de código, testes de rotas e projetos práticos focados em arquitetura web, integração de sistemas e padrões de mercado.

---

## 📚 Tópicos de Estudo

O conteúdo está organizado (ou será estruturado) cobrindo os seguintes pilares:

- [x] **Fundamentos da Web & Protocolo HTTP**
  - Verbos HTTP (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`)
  - Códigos de Status (`2xx`, `3xx`, `4xx`, `5xx`)
  - Cabeçalhos (Headers), Query Parameters e Path Parameters
- [ ] **Arquitetura REST e Padrões RESTful**
  - Boas práticas de design de endpoints
  - HATEOAS e versionamento de APIs
- [ ] **Autenticação e Segurança**
  - Autenticação Baseada em Tokens (JWT)
  - Conceitos de OAuth 2.0 e cabeçalhos de autorização (`Bearer Token`)
- [ ] **Documentação e Especificação**
  - Padrão OpenAPI / Swagger
  - Testes e coleções utilizando Postman / Insomnia
- [ ] **Consumo e Construção de APIs**
  - Requisições assíncronas e síncronas
  - Validação de dados e tratamento de erros
